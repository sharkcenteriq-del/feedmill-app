== الطريقة السهلة (بناء تلقائي مجاني على GitHub، ينتج ملف التنصيب و APK) ==
1) أنشئ حساباً مجانياً على github.com ثم مستودعاً جديداً (New repository).
2) ارفع كل محتويات هذا المجلد إلى جذر المستودع (الملفات: package.json و main.js و preload.js و prepare.js و index.html و icon.png و capacitor.config.json و مجلد .github). كل الملفات في المستوى الأول بدون مجلدات فرعية ما عدا .github.
3) افتح تبويب Actions ثم Build apps ثم Run workflow (أو سيعمل تلقائياً بعد الرفع).
4) بعد 5 إلى 10 دقائق افتح التشغيل المكتمل ونزّل من Artifacts:
   - Windows-Installer  ← ملف FeedMill-Setup.exe (تنصيب على الكومبيوتر)
   - Android-APK        ← ملف app-debug.apk (تنصيب على الأندرويد)

== بناء نسخة ويندوز على جهازك ==
ثبّت Node.js (نسخة LTS) ثم افتح CMD داخل المجلد ونفّذ:
   npm install
   npm run dist
يظهر ملف التنصيب داخل مجلد dist. للتجربة بدون تنصيب: npm start

== ملاحظات ==
- البرنامج يعمل بالكامل بدون إنترنت (الخطوط ومكتبة Excel مضمنة).
- نسخة الكومبيوتر تحفظ نسخة احتياطية تلقائية يومية (آخر 14 يوماً) في مجلد backups داخل بيانات البرنامج.
- في الأندرويد يظهر ملف Excel أو النسخة الاحتياطية عبر نافذة المشاركة (حفظ في الملفات أو إرسال).
- عند تنصيب APK اسمح بالتنصيب من مصدر غير معروف.
